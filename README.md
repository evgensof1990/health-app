# Помощник: здоровье и развитие

Одно приложение на четыре направления: питание и вес, саморазвитие и баланс, самооценка и юмор, стиль.

Стек тот же, что у планнера: React + Vite, Android-сборка через Capacitor, свой Node-сервер. Веб-версия открывается на `https://health.myrenthub.ru`.

## Питание

- Нажми на микрофон и скажи, что съел: «тарелка борща со сметаной и кусок чёрного хлеба». Голос распознаёт Yandex SpeechKit, а ИИ (Alice AI из Yandex AI Studio) раскладывает сказанное на продукты, считает калории и БЖУ, ставит оценку и пишет короткий комментарий с учётом того, что уже съедено за день.
- Спроси: «хочу копчёную куриную ножку, это ок?» — ответ учитывает остаток нормы и время суток.
- Скажи «вес 91,4», и вес запишется.
- Можно сфотографировать тарелку, с подписью или без.
- Запись можно исправить («не 200, а 300 г гречки»), и ИИ пересчитает её. Можно поменять время или удалить запись.
- Норма считается по формуле Миффлина — Сан-Жеора с мягким дефицитом (по умолчанию около 0,3 кг в неделю), белок от желаемого веса.
- График веса показывает среднее за 7 дней, чтобы дневные скачки воды не сбивали с толку.

## Развитие

- **Чтение.** Текущая книга с прогрессом, кнопка «Почитал» (минуты и страница), серия дней. Стартовая подборка из 10 книг для возвращения к чтению и подбор 5 книг под интересы через ИИ.
- **Привычки.** 3–4 привычки на выбор (или свои), отметка за день, точки за неделю и серии.
- **Баланс.** Колесо из 8 сфер раз в неделю-две, сравнение с прошлым разом и 2–3 конкретных шага на неделю от ИИ.
- **Советы.** Совет дня про быт, сон, досуг и баланс; внедрённые отмечаются.

## Я: самооценка и юмор

- **Практика дня.** Программа из 28 пятиминутных практик, чередуются самооценка и юмор.
- **Победы.** Дневник «три победы за день».
- **Мысли.** Разбор задевающей мысли по методам КПТ: искажение, трезвый взгляд, маленькое действие.
- **Юмор.** Тренажёр остроумия: ситуация и техника, твой ответ, оценка 1–10, как усилить, варианты.

## Стиль

- **Гайд.** Пять вопросов, и ИИ собирает личный гайд: цвета, базовая капсула с приоритетами, правила, чего избегать.
- **Гардероб.** Фото вещи, и ИИ (Qwen в AI Studio) определяет её и решает: оставить, с оговорками или заменить. Фото хранятся на сервере.
- **Образ.** Образ из своих вещей под повод и погоду, плюс чего не хватает.
- **Покупки.** Список с приоритетами, пополняется из гайда и образов.

Почти везде можно надиктовать голосом.

## Установка

### 1. Ключ Yandex AI Studio

Текст понимает Alice AI LLM, фото одежды и еды разбирает Qwen3.6 (обе модели в Yandex AI Studio, оплата рублями с того же счёта, что и SpeechKit).

1. https://console.yandex.cloud → нужный каталог. Его идентификатор (вида `b1g…`) виден на странице каталога, скопируй.
2. Сервисные аккаунты → тот, что для SpeechKit, или новый → Права доступа → добавь роль `ai.languageModels.user`.
3. В аккаунте → Создать новый ключ → API-ключ. Область действия: `yc.ai.foundationModels.execute` (можно вместе с `yc.ai.speechkitStt.execute`). Скопируй секрет: показывается один раз.

Вместо Яндекса можно оставить Claude через Cloudflare-воркер (`deploy/ai-proxy-worker.js`): задай в `/etc/health.env` `AI_PROVIDER=claude`, `AI_PROXY_URL` и `AI_PROXY_SECRET`.

### 2. Сервер

Нужна A-запись `health.myrenthub.ru` на тот же сервер, где работает планнер.

```bash
git clone https://github.com/evgensof1990/health-app.git && cd health-app
sudo bash deploy/install.sh
```

Скрипт спросит идентификатор каталога и API-ключ AI Studio, возьмёт ключ SpeechKit из настроек планнера (если он там есть) и выдаст ключ доступа для приложения. Если сервер уже был установлен с Claude, повторный запуск просто допишет ключ Яндекса. Обновление: `git pull && sudo bash deploy/install.sh`.

### 3. Приложение

APK собирается GitHub Actions при каждом пуше в `main`: см. раздел Releases. При первом запуске укажи адрес сервера и ключ доступа, затем заполни профиль.

## Разработка

```bash
npm install && (cd server && npm install)
npm test                 # тесты сервера и расчётов (ИИ подменяется заглушкой)
node test/fake-claude.js 3399 &
cd server && HEALTH_TOKEN=local-token-0123456789 YANDEX_API_KEY=test-yandex-key YANDEX_FOLDER_ID=local YANDEX_AI_URL=http://127.0.0.1:3399/v1 node index.js &
npm run dev              # http://localhost:5173, сервер http://127.0.0.1:3310
```

Переменные сервера: `HEALTH_TOKEN`, `YANDEX_FOLDER_ID`, `YANDEX_API_KEY`, `YANDEX_TEXT_MODEL` (по умолчанию `aliceai-llm`), `YANDEX_VISION_MODEL` (`qwen3.6-35b-a3b`), `SPEECHKIT_API_KEY`, `PORT` (3310), `DATA_DIR`, `ALLOWED_ORIGINS`. Для Claude: `AI_PROVIDER=claude`, `AI_PROXY_URL`, `AI_PROXY_SECRET`, `AI_MODEL`, `AI_EFFORT`.
