# Помощник: здоровье и развитие

Одно приложение на четыре направления: питание и вес, саморазвитие и баланс, самооценка и юмор, стиль.

Стек тот же, что у планнера: React + Vite, Android-сборка через Capacitor, свой Node-сервер. Веб-версия открывается на `https://health.myrenthub.ru`.

## Питание

- Нажми на микрофон и скажи, что съел: «тарелка борща со сметаной и кусок чёрного хлеба». Голос распознаёт Yandex SpeechKit, а Claude раскладывает сказанное на продукты, считает калории и БЖУ, ставит оценку и пишет короткий комментарий с учётом того, что уже съедено за день.
- Спроси: «хочу копчёную куриную ножку, это ок?» — ответ учитывает остаток нормы и время суток.
- Скажи «вес 91,4», и вес запишется.
- Можно сфотографировать тарелку, с подписью или без.
- Запись можно исправить («не 200, а 300 г гречки»), и Claude пересчитает её. Можно поменять время или удалить запись.
- Норма считается по формуле Миффлина — Сан-Жеора с мягким дефицитом (по умолчанию около 0,3 кг в неделю), белок от желаемого веса.
- График веса показывает среднее за 7 дней, чтобы дневные скачки воды не сбивали с толку.

## Развитие

- **Чтение.** Текущая книга с прогрессом, кнопка «Почитал» (минуты и страница), серия дней. Стартовая подборка из 10 книг для возвращения к чтению и подбор 5 книг под интересы через Claude.
- **Привычки.** 3–4 привычки на выбор (или свои), отметка за день, точки за неделю и серии.
- **Баланс.** Колесо из 8 сфер раз в неделю-две, сравнение с прошлым разом и 2–3 конкретных шага на неделю от Claude.
- **Советы.** Совет дня про быт, сон, досуг и баланс; внедрённые отмечаются.

## Я: самооценка и юмор

- **Практика дня.** Программа из 28 пятиминутных практик, чередуются самооценка и юмор.
- **Победы.** Дневник «три победы за день».
- **Мысли.** Разбор задевающей мысли по методам КПТ: искажение, трезвый взгляд, маленькое действие.
- **Юмор.** Тренажёр остроумия: ситуация и техника, твой ответ, оценка 1–10, как усилить, варианты.

## Стиль

- **Гайд.** Пять вопросов, и Claude собирает личный гайд: цвета, базовая капсула с приоритетами, правила, чего избегать.
- **Гардероб.** Фото вещи, и Claude определяет её и решает: оставить, с оговорками или заменить. Фото хранятся на сервере.
- **Образ.** Образ из своих вещей под повод и погоду, плюс чего не хватает.
- **Покупки.** Список с приоритетами, пополняется из гайда и образов.

Почти везде можно надиктовать голосом.

## Установка

### 1. Cloudflare Worker для Claude

API Anthropic не принимает запросы с российских IP, поэтому сервер ходит к Claude через воркер.

1. Ключ API: https://console.anthropic.com → API Keys → Create Key. Пополни баланс на $5–10: при обычном использовании (10–15 записей в день) уходит примерно $3–8 в месяц.
2. Cloudflare → Workers & Pages → Create → Hello World → Deploy, затем Edit code: вставь `deploy/ai-proxy-worker.js` → Deploy.
3. Settings → Variables and Secrets: `ANTHROPIC_API_KEY` (ключ из шага 1) и `PROXY_SECRET` (выдаст скрипт установки в шаге 2), оба типа Secret.

### 2. Сервер

Нужна A-запись `health.myrenthub.ru` на тот же сервер, где работает планнер.

```bash
git clone https://github.com/evgensof1990/health-app.git && cd health-app
sudo bash deploy/install.sh
```

Скрипт спросит адрес воркера, возьмёт ключ SpeechKit из настроек планнера (если он там есть) и выдаст два значения: `PROXY_SECRET` для воркера и ключ доступа для приложения. Обновление: `git pull && sudo bash deploy/install.sh`.

### 3. Приложение

APK собирается GitHub Actions при каждом пуше в `main`: см. раздел Releases. При первом запуске укажи адрес сервера и ключ доступа, затем заполни профиль.

## Разработка

```bash
npm install && (cd server && npm install)
npm test                 # тесты сервера и расчётов (Claude подменяется заглушкой)
node test/fake-claude.js 3399 &
cd server && HEALTH_TOKEN=local-token-0123456789 AI_PROXY_URL=http://127.0.0.1:3399 AI_PROXY_SECRET=test-proxy-secret-123 node index.js &
npm run dev              # http://localhost:5173, сервер http://127.0.0.1:3310
```

Переменные сервера: `HEALTH_TOKEN`, `AI_PROXY_URL`, `AI_PROXY_SECRET`, `SPEECHKIT_API_KEY`, `AI_MODEL` (по умолчанию `claude-opus-5-5`), `AI_EFFORT` (`medium`), `PORT` (3310), `DATA_DIR`, `ALLOWED_ORIGINS`.
